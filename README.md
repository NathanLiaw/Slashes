# Slashes Roguelike Hack-and-Slash Game
This is a roguelike hack-and-slash game developed for the COS20007 Object-Oriented Programming course. The project serves as a practical demonstration of OOP principles, showcasing concepts such as encapsulation, inheritance, and polymorphism in the context of game development.

Inspired by Vampire Survivors and HoloCure, this game combines exciting gameplay with a focus on clean and modular code design, making it both fun to play and a valuable learning experience.

## Features
1. Timed Survival Mode (10-Minute Challenge)
2. Weapon and Item Drops from Enemies
3. Adaptive AI and Enemy Variety

## Prerequisites
To play the game, simply download the SplashKit library. You can install it by visiting the official SplashKit website or using the NuGet Package Manager in Visual Studio by running the command Install-Package SplashKit. After downloading and installing SplashKit, just run the game and enjoy!
